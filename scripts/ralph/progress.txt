## Codebase Patterns
- Project uses Next.js 16 with Tailwind CSS v4 (CSS-based config via `@theme inline` in globals.css, not tailwind.config.js)
- shadcn/ui was initialized manually (components.json + CSS variables) since ui.shadcn.com is unreachable from this environment

- cn() utility at src/lib/utils.ts uses clsx + tailwind-merge
- Font is Inter loaded via next/font/google with variable `--font-inter`
- HTML lang is `pt-BR` — all user-facing text should be in Portuguese
- Prisma 7.7.0 with PostgreSQL provider. `prisma generate` requires network (binaries.prisma.sh blocked). Schema at prisma/schema.prisma has 10 models + 6 enums.
- Typecheck with `npx tsc --noEmit` — works without prisma generate having run
- PrismaClient import uses `require("@prisma/client")` because generated types don't exist (prisma generate blocked). Singleton in src/lib/prisma.ts.
- TypeScript interfaces for API shapes live in src/types/ (hotel.ts, survey.ts, google-places.ts, dashboard.ts)
- shadcn/ui components are in src/components/ui/ — created manually (not via CLI). They use Radix UI primitives + class-variance-authority (CVA) + cn() utility.
- Radix UI packages installed: @radix-ui/react-slot, react-dialog, react-dropdown-menu, react-separator, react-slider, react-progress
- @googlemaps/js-api-loader v2 uses functional API: `setOptions({key})` + `importLibrary("maps")`, NOT `new Loader()`. `setOptions` must be called once globally.
- Next.js 16 route handler params are Promises — must `await params` before destructuring
- Next.js 16 `cookies()` is async — must `await cookies()`
